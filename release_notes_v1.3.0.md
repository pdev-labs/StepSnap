### StepSnap v1.3.0 - Pause & Custom Sessions ⏸️
- **Custom Sessions:** When you start StepSnap, you can now type a custom name for the screenshot folder. If you leave it blank, it falls back to the default date/time format.
- **Global Pause/Resume:** You can now press **`F9`** at any time to temporarily pause the automatic screenshots! Press it again to resume. Great for when you need to answer a message without filling your folder with junk screenshots.
